# Версии BE

Формат: `1.XX[буква][подверсия][-alpha|-beta]` (в билде: `be-…`).

| Часть             | Правило                                                         |
|-------------------|-----------------------------------------------------------------|
| `1.06` → `1.07`   | Число после точки только растёт                                 |
| `a`, `b`, …       | Этап по алфавиту; на первом выпуске линии буквы может не быть   |
| `1`, `2`, …       | Мелкие фиксы внутри буквы; может не быть                        |
| `-alpha`, `-beta` | Тестовая сборка; **ниже** версии без суффикса                   |

**Порядок:** minor ↑ → буква ↑ → подверсия ↑ → стадия: `alpha` < `beta` < релиз.

**Пример:** `1.06` < `1.06a1-alpha` < `1.06a1-beta` < `1.06a1` < `1.06a3` < `1.06b` < `1.07`
