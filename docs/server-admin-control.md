# Управление BE-функциями на сервере Quake 3

## Отключение BE-функций

### Основной переключатель: be_enabled

Все BE-функции можно полностью отключить, установив `be_enabled 0` на клиенте. Это отключит все расширенные возможности OSP2-BE.

```c
// Полностью отключить все BE-функции
seta be_enabled "0"
```

### Серверное управление функциями

Сервер может выборочно отключать определенные BE-функции через configstring. Это позволяет администраторам серверов контролировать, какие функции будут доступны игрокам.

#### Доступные для отключения функции:

| Битовая маска | Функция         | Описание                            |
|---------------|-----------------|-------------------------------------|
| 1             | Team wh         | Wallhack союзников, global pos (бит 4 `cg_friendsWallhack`) |
| 2             | Model sound     | Выбор звуков моделей                |
| 4             | Alt grenades    | Альтернативные гранаты              |
| 8             | Enemy lightning | Цвет молнии противника              |
| 16            | Mark teammate   | Маркировка союзников                |
| 32            | Alt shadow      | Альтернативная тень                 |
| 64            | Alt blood       | Альтернативная кровь                |
| 128           | Alt plasmagun   | Альтернативная плазма               |
| 256           | Outline         | Контуры игроков                     |
| 512           | Team indicator  | Индикатор команды                   |
| 1024          | Damage info     | Информация о нанесённом уроне       |
| 2048          | Fullbright      | Полная яркость моделей/оружия       |
| 4096          | Team tasks      | Командные задачи                    |
| 8192          | No explosions   | Отключение взрывов                  |
| 16384         | Team frozen     | Wallhack замороженных союзников     |
| 32768         | HUD markers     | Маркеры на HUD (игроки)             |
| 65536         | Replace steps   | Убрать звук шагов по метал. поверхн.|
| 131072        | Autojump        | Автоматический прыжок               |
| 262144        | Hitbox          | Запретить отображение хитбокса      |

#### Как отключить функции на сервере:

1. **Вычислите значение configstring:**
   - Суммируйте битовые маски функций, которые хотите отключить
   - Например, чтобы отключить damage info (1024) и fullbright (2048): 1024 + 2048 = 3072

2. **Установите configstring 888:**
   ```c
   // Отключить damage info и fullbright
   set cs 888 "3072"
   ```

3. **Отключить все функции:**
   ```c
   set cs 888 "524287"
   ```

### Проверка отключенных функций

Игроки могут проверить, какие функции отключены на сервере, используя команду:

```
/allowedfeatures
```

Это покажет список всех BE-команд и укажет, какие функции недоступны.

## Configstring 889: каталог предметов для PUI (спектаторский HUD)

Клиенты OSP2-BE с элементами SuperHUD **Spectator_ItemSpawns** / **ItemPickups** ожидают, что сервер задаёт список отслеживаемых пикапов в **CS 889** и при подборе шлёт серверную команду **`pui`**.

### CS 889 — формат `v4`

Строка начинается с **`v4`**, далее сегменты через **`;`**:

| Сегмент     | Вид формата              | Назначение                                  |
|-------------|--------------------------|---------------------------------------------|
| Пэд команды | S,side,padIdx,id,id,...  | Несколько предметов на одном team spawn pad |
| Одиночный   | I,id                     | Пикап вне team pad                          |

- **side** — `0` нейтральный, `1` красные, `2` синие (должен совпадать с полем side в каждом `id`).
- **padIdx** — `0`…`15`, группирует иконки на одном пэде.
- В сегменте **`S`** первый **id** — основная иконка строки HUD, остальные **id** — бейджи поверх неё (порядок в сегменте).

**id** — целое **0**…**1022** (`PUI_ID`):

```
id = (side << 8) | (slot << 4) | type
```

| type | Предмет       |
|-----:|:--------------|
|    0 | Mega Health   |
|    1 | Red Armor     |
|    2 | Yellow Armor  |
|    3 | Quad          |
|    4 | Battle Suit   |
|    5 | Regen         |
|    6 | Invis         |
|    7 | Haste         |
|    8 | Flight        |

**slot** — `0`…`15` (слот на пэде внутри `PUI_ID`). **side** в формуле — тот же, что в сегменте `S`.

Пример (красный MH + RA на пэде `1`, слоты 0 и 1; нейтральный Quad отдельно):

```c
// MH: type=0, side=1, slot=0 → 256
// RA: type=1, side=1, slot=1 → 272
// QD: type=3, side=0, slot=0 → 3
set cs 889 "v4;S,1,1,256,272;I,3"
```

Пустая или не-`v4` строка — каталог на клиенте не строится. При смене CS 889 таймеры респавна, уже известные клиенту, по возможности сохраняются.

### Команда `pui` при подборе

После подбора предмета из каталога сервер шлёт **`pui` только зрителям** (игроки в команде команду не обрабатывают), через `trap_SendServerCommand` / аналог:

```
pui <cmd> <readyTime>
```

- **readyTime** — `serverTime`, когда предмет снова доступен (мс; `0` — сброс таймера на этом слоте).
- **cmd** — упакованное целое `PUI_CMD(picker, pickId, nextId)`:
  - **picker** — номер клиента `0`…`63` (`MAX_CLIENTS`);
  - **pickId** — **id** из CS 889;
  - **nextId** — следующий **id** в ротации на пэде, или **1023** если не используется (клиент может взять следующий по порядку в сегменте `S`).

```
cmd = (picker << 20) | (pickId << 10) | (nextId & 1023)
```

Пример: клиент `2` подобрал `256`, респавн через 35 с (`readyTime = serverTime + 35000`), явный следующий слот `272`:

```c
// cmd = (2 << 20) | (256 << 10) | 272
// только TEAM_SPECTATOR, не trap_SendServerCommand(-1, ...)
for (i = 0; i < level.maxclients; i++) {
    if (level.clients[i].pers.connected != CON_CONNECTED) {
        continue;
    }
    if (level.clients[i].sess.sessionTeam != TEAM_SPECTATOR) {
        continue;
    }
    trap_SendServerCommand(i, va("pui %i %i", cmd, readyTime));
}
```

## Configstring 890–900: layout пикапов (SI3 / SI4)

Сервер передаёт финальные координаты пикапов и состав map-team слотов. Если **890** не в формате ниже — клиент берёт **QITM** из mapdata.

| Формат            | CS 890                         | CS 891–900        |
|-------------------|--------------------------------|-------------------|
| SI3 (metarena)    | строка SI3                     | весь payload      |
| SI4               | SI4 и начало payload           | продолжение       |

Группа: `tok[/tok2]@x,y,z` (0.1 u). **`/`** — альтернативы одного слота. Категории призраков — **`cg_shadowItems`**.
