# Расширенные возможности OSP2-BE для серверов Quake 3

## Функции, требующие серверной поддержки

#### cg_damagePlums (Плавающие числа урона)
- **Описание:** Отображает плавающие числа с количеством нанесенного урона
- **Серверный cvar:** `g_damagePlums`
- **Опциональный клиентский cvar:** `cg_damagePlumsWeapons` (фильтр по оружию)
- **Значения `cg_damagePlumsWeapons` (битовая маска):**
  - `1` - Gauntlet (Кулак)
  - `2` - Machine Gun (Пулемёт)
  - `4` - Shotgun (Дробовик)
  - `8` - Grenade Launcher (Гранатомёт)
  - `16` - Rocket Launcher (Ракетница)
  - `32` - Lightning Gun (Шафт)
  - `64` - Railgun (Рейлган)
  - `128` - Plasma Gun (Плазмаган)
  - `256` - BFG

#### cg_autohop (Автоматический прыжок)
- **Описание:** Автоматический прыжок при удерживании кнопки прыжка
- **Серверный cvar:** `pmove_autohop`
```c
// На сервере
set pmove_autohop "0"      // Отключить автопрыжок
set pmove_autohop "1"      // Включить, игроки не могут отключить
set pmove_autohop "2"      // Включить, игроки могут управлять
```

#### CS_OSP2BE_SHADOW_ITEMS (Configstring 890–900)

- **Описание:** Layout для `cg_shadowItems`. **SI3:** 890=`SI3`, данные 891–900. **SI4:** 890=`SI4`+payload, далее 891–900. Иначе QITM. См. `docs/server-admin-control.md`.

#### CS_OSP2BE_ITEM_TRACK (Configstring 889) — PUI / спектаторский HUD

- **Описание:** Каталог пикапов для таймеров и уведомлений о подборе у зрителей (SuperHUD `Spectator_ItemSpawns*`, `ItemPickups1–8`). Сервер задаёт **CS 889** (`v4;…`) и при подборе шлёт **`pui <cmd> <readyTime>`** только клиентам в режиме зрителя.
- **Формат CS 889:** `v4;S,side,padIdx,id[,id…];I,id;…` — сегменты `S` (team pad) и `I` (одиночный). **id** = `(side<<8)|(slot<<4)|type` (типы 0–8: MH, RA, YA, Quad, BS, Regen, Invis, Haste, Flight).
- **Команда `pui`:** `cmd = (clientNum<<20)|(pickId<<10)|nextId`, **nextId** `1023` если нет явного «следующего»; **readyTime** — `serverTime` респавна. Рассылка — только спектаторам (`TEAM_SPECTATOR`), не broadcast `-1`.
- Подробно: `docs/server-admin-control.md` (раздел CS 889).

#### CS_OSP2BE_TOURNEY_MODE (Configstring — в разработке)

- **Описание:** Серверная битовая маска ограничений для турнирного режима (номер configstring уточняется отдельно от 889).
- **Битовая маска:**
  - `1` - fps lock
  - `2` - disable mouse scripts

## Функции, которые работают, но могут быть улучшены серверной логикой

#### cg_respawnWeapon (Оружие при респауне)
- **Описание:** Выбор оружия, которое будет автоматически выбрано при респауне
- **Для полной работы на сервере:** Необходимо проверять настройку клиента и выдавать соответствующее оружие при респауне. Без этого игрок получит оружие по умолчанию и затем переключится на выбранное.
- **Значения:**
  - `0` - Использовать оружие сервера по умолчанию
  - `1` - Gauntlet (Кулак)
  - `2` - Machinegun (Пулемет)
  - `3` - Shotgun (Дробовик)
  - `4` - Grenade Launcher (Гранатомет)
  - `5` - Rocket Launcher (Ракетница)
  - `6` - Lightning Gun (Шафт)
  - `7` - Railgun (Рейлган)
  - `8` - Plasma Gun (Плазмаган)

```c
// На клиенте
seta cg_respawnWeapon "7"  // Автоматически выбирать рейлган при респауне
seta cg_respawnWeapon "0"  // Использовать оружие по умолчанию
```
