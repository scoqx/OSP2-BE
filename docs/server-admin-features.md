# Расширенные возможности OSP2-BE для серверов Quake 3

## Функции, требующие серверной поддержки

#### cg_damagePlums (Плавающие числа урона)
- **Описание:** Отображает плавающие числа с количеством нанесенного урона
- **Серверный cvar:** `g_damagePlums`

#### cg_autohop (Автоматический прыжок)
- **Описание:** Автоматический прыжок при удерживании кнопки прыжка
- **Серверный cvar:** `pmove_autohop`
```c
// На сервере
set pmove_autohop "0"      // Отключить автопрыжок
set pmove_autohop "1"      // Включить, игроки не могут отключить
set pmove_autohop "2"      // Включить, игроки могут управлять
```

## Функции, которые работают, но могут быть улучшены серверной логикой

#### cg_respawnWeapon (Оружие при респауне)
- **Описание:** Выбор оружия, которое будет автоматически выбрано при респауне
- **Для полной работы на сервере:** Необходимо проверять настройку клиента и выдавать соответствующее оружие при респауне. Без этого игрок получит оружие по умолчанию и затем переключится на выбранное.
- **Значения:**
  - `0` - Использовать оружие сервера по умолчанию
  - `1` - Gauntlet (Кулак)
  - `2` - Machinegun (Пулемет)
  - `3` - Shotgun (Дробовик)
  - `4` - Grenade Launcher (Гранатомет)
  - `5` - Rocket Launcher (Ракетница)
  - `6` - Lightning Gun (Шафт)
  - `7` - Railgun (Рейлган)
  - `8` - Plasma Gun (Плазмаган)

```c
// На клиенте
seta cg_respawnWeapon "7"  // Автоматически выбирать рейлган при респауне
seta cg_respawnWeapon "0"  // Использовать оружие по умолчанию
```
