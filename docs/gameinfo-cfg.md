# gameinfo.cfg

Опционально в корне игры/мода. UI читает блок `ui` при старте.

```
AddCvar
{
    ui
    {
        be_statusServer1 = 127.0.0.1:27888;
        be_statusServer2 = 127.0.0.1:27889;
    }

    cgame
    {

    }
}
```

| Ключ (в `ui`) | По умолчанию |
|---------------|----------------|
| `be_statusServer1` | `127.0.0.1:27888` |
| `be_statusServer2` | `127.0.0.1:27889` |

Значение: `хост:порт`. Блок `cgame` пока не используется. 
Строки с `#` в начале (после пробелов) — комментарий.
