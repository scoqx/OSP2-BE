# Resources Credits

This document lists the sources of resources used in OSP2-BE.

## Icons

Most new icons used in OSP2-BE were sourced from [Flaticon](https://www.flaticon.com).

- **Source**: [Flaticon](https://www.flaticon.com)
- **Note**: Original authors were not recorded during collection. All icons have been edited and modified for use in OSP2-BE.

## Sounds

Audio files used in OSP2-BE were sourced from [Freesound.org](https://freesound.org).

- **Source**: [Freesound.org](https://freesound.org)
- **License**: Please refer to individual sound file licenses on Freesound.org

## Player Model Skins

Fullbright skins for player models were sourced from [CPMA (Challenge ProMode Arena)](https://playmorepromode.com/).

- **Source**: [CPMA](https://playmorepromode.com/)
- **Note**: Fullbright player model skins were taken from CPMA
