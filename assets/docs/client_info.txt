Дополнительные возможности OSP2-BE

-=Переменная, хранящая информацию о сборке Quake 3 Arena=-

Файл `cversion` (без расширения) в папке OSP позволяет создать переменную, доступную серверу.

-Пример содержимого файла:
===
Compilation "Name" Version "version"
===

-=Кастомные шрифты=-

Файл `fonts.cfg` в папке OSP позволяет регистрировать шрифты без изменений в коде.

-Пример содержимого файла:
===
"Font name" "gfx/2d/file.cfg"
"Another font name" "gfx/2d/file2.cfg"
===

-= Кастомные конфиги (customConfig) =-

Папка `beconfigs` в OSP позволяет добавить новую клиентскую команду без правки кода.

Если в этой папке находится файл вида:
customConfig_<имя>.cfg

то в клиенте автоматически становится доступна команда:
/get<имя>

При её вызове выполняется содержимое соответствующего файла.

Правила:
- Имя файла: customConfig_<имя>.cfg
- <имя> — латиница, без пробелов
- Путь к файлу: beconfigs/customConfig_<имя>.cfg
- Максимальный размер файла: 64 КБ

Пример:
Файл: customConfig_Elite.cfg
Команда в клиенте: /getElite
