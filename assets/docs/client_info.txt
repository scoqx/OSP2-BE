Дополнительные возможности OSP2-BE

-=Переменная, хранящая информацию о сборке Quake 3 Arena=-

Файл `cversion` (без расширения) в папке OSP позволяет создать переменную, доступную серверу.

-Пример содержимого файла:
===
Compilation "Name" Version "version"
===

-=Кастомные шрифты=-

Файл `fonts.cfg` в папке OSP позволяет регистрировать шрифты без изменений в коде.

-Пример содержимого файла:
===
"Font name" "gfx/2d/file.cfg"
"Another font name" "gfx/2d/file2.cfg"
===
